# Student Management System

A simple Student Management System built with JavaScript and Node.js to manage student data, calculate grades, determine student performance, and generate reports.

## Features

- Store student information using JavaScript objects.
- Organize student data in arrays.
- Calculate the average grade for each student.
- Determine whether a student passed or failed.
- Find the top-performing student.
- Search for students by ID.
- Get a list of student names.
- Filter passing students.
- Generate individual student reports.
- Generate reports for all students.
- Generate a report for the top student.
- Convert reports to JSON and parse them back into JavaScript objects.
- Organize code using JavaScript Modules (`import` / `export`).

## How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project directory:

```bash
cd student-management
```

3. Run the application:

```bash
node app.mjs
```
